# 🏥 Knee Osteoarthritis Risk & X-Ray Analyzer

An interactive web application built with Python, Streamlit, and Machine Learning that evaluates clinical knee osteoarthritis risk factors and processes arthroplasty X-ray images.

## 🚀 Features
- **Clinical Risk Assessment:** Predicts the risk of knee osteoarthritis using patient health metrics (Age, BMI, Pain Score, History of Injury).
- **X-Ray Image Enhancement:** Uploads and applies CLAHE contrast adjustment and edge detection to analyze knee arthroplasty images.

## 🛠️ Tech Stack
- Python
- Streamlit
- Scikit-Learn
- OpenCV & Matplotlib
